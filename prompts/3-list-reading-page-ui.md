새 링크 페이지의 UI를 구현할 것

# 페이지 구성

    - Write(app\@modal\(.)diary\page.tsx)와 연동하여 구현할 것
    - 백그라운드에 사각형 테두리를 이쁘게 구현하고, 제목과 컴포넌트 간 분리를 할 것
    - 컴포넌트끼리 구분될 수 있도록 희미하게 박스를 구현할 것

    - 상단 헤더
    - 좌측: ‘그날을 거닐다’로 텍스트 로고 배치할 것
    - 우측: 컴포넌트 화면 최소화,최대화,닫기 버튼을 배치할 것
    - 메인 섹션
    - 상단에 좌측에서 우측으로 순차적으로 files.png, calendar.png, search.png icon을 사용하여 배치하고, search.png icon 좌측에 검색 위한 텍스트 인풋 설정할 것
    - icon은 C:\webdev\diary\images를 사용할 것
    - icon은 바탕화면 비율에 맞게 조정하고, 텍스트 사이즈는 icon과 맞출 것
    - top-down방식인, 최신 날짜 순으로 배치되도록 저장된 글 목록 리스트를 만들 것
    - 한 페이지에 글 목록이 5개까지 나열할 것
    - 글 5개가 넘어가면, 상하로 스크롤 되도록 스크롤바를 목록 우측에 배치할 것
    - 목록을 클릭하면, 글 읽기용 새 페이지가 팝업 되게 구현할 것
        - 내용은 아직 구현하지 말 것

    - 글 목록 컴포넌트 안에 저장된 년/월/일/요일을 좌측에 배치할 것
    - 글 목록 컴포넌트 안에 저장된 제목을 보여줄 것

# 주의 사항

    - 컴포넌트 단위로 적절히 분할해서 구현할 것
    - 결과는 컴포넌트 단위로 보고할 것
    - 이미 만들어둔 컴포넌트를 최대한 활용할 것

# 수정 설정 사항

    - 상단 헤더 우측 컴포넌트 화면 최소화,최대화,닫기 버튼을 아래와 같이 구현할 것
        - 최소화 버튼을 클릭할 시 모달창 최소화 할 것
            - 최소화 버튼을 한번 이상 클릭해도, 최소화 상태로 나둘 것
        - 최대화 버튼을 클릭할 시 최소화로 완전히 닫힌 모달창을 다시 원 상태로
          키울 것
            - 최대화 버튼을 한번 이상 클릭해도, 최대화 상태로 나둘 것
    - 모달창이 바탕화면 내에서 자유롭게 이동 가능하게 구현할 것
        - 바탕화면 밖으로 벗어나지 않게 이동 가능하게 구현할 것
        - 바탕화면 클릭해도, 모달창의 닫기 버튼을 누르지 않으면 초기화되지 않게 구현할 것

# 추가 설정 사항

    - icon을 클릭하면, 새 페이지로 전환되게 구성할 것
        - files.png를 클릭하면, Write(app\@modal\(.)diary\page.tsx)로 전환되게 구현할 것
        - calendar.png를 클릭하면, 달력 검색 페이지로 전환되게 구현할 것
            - 아직 페이지 구현 안했으니, 페이지 전환만 구현할 것
        -files.png, calendar.png, search.png를 클릭하면, 눌러지는 이벤트가
         발생하도록 구현할 것
        - 검색 인풋란에 원하는 등록된 단어나 제목을 작성 후, search.png를 클릭하면
          해당 글 목록 검색되게 구현할 것
