새 링크 페이지(데이터 관리 모달창)의 UI 사이즈 수정

# 수정 사항(1)

- 중앙 상단 컴포넌트의 '기억의 날개’ 컴포넌트 내 구성원이 모두 한번에
  보이지 않게 스크롤되고 있으니, 세로 사이즈를 조정해서 한 화면에
  보이게 구현할 것
- 나머지 ‘기억의 귀환’ 와 ’기억의 소멸’ 컴포넌트 사이즈도 '기억의 날개
  컴포넌트 사이즈에 맞출 것

# 수정 사항(2)

- '내보내기 완료 후 내보내기한 글을 삭제합니다.' 텍스트가 한 화면에 보이지
  않고, 스크롤해서 내려야 보이니, 조정할 것
  또한, 내보내기 버튼을 텍스트 우측 가장자리 끝에 맞출 것

# 주의 사항

    - 컴포넌트 단위로 적절히 분할해서 구현할 것
    - 결과는 컴포넌트 단위로 보고할 것
    - 이미 만들어둔 컴포넌트를 최대한 활용할 것
