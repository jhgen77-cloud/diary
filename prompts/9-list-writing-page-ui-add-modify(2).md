시간을 붙잡다 모달창 수정

# 페이지 구성

# 추가 수정 요청 사항(1)

- 기분 icon을 선택하면 자동 저장이 되게 하고, save.png 일부를 색상이 파란색으로 바뀌게 구현할 것
  -> no-select.png를 클릭하면, save-saved.png에서 save.png로 원복시킬 것
- 제목, 글 내용, no-select.png일 때, 첨부된 이미지가 없을 때, 모두 초기화 상태면, save.png와
  image-attachment.png로 원복시킬 것

# 추가 수정 요청 사항(2)

- 이미지가 첨부될 때, 자동 저장 기능 삭제하고, save-saved.png로 변하는 것도 삭제할 것
  -> 이미지 첨부 모달창이 닫혀도, 다시 이미지 첨부 창 오픈할 때 이미지가 남아 있는 기능은 구현할 것
- 기분 icon을 선택하면 자동 저장 기능 삭제하고, save-saved.png로 변하는 것도 삭제할 것
  -> 기분 icon을 선택하면, 선택된 icon에 선택됐다는 표시만 할 것
- 시간을 붙잡다 모달창에, 글 내용을 적지 않고, 저장 기능을 누르면 아래와 같이 구현할 것
  - 알림창(모달창)이 띄워지면서, '[일기내용]을 입력하세요'라고 알림창 가운데에 배치하고, 텍스트 좌측에
    warning-sign.png를 사용할 것
  - 확인 버튼을 클릭하면 알림창이 사라질 것
- 글 내용을 적고, save.png 버튼을 클릭하면, 저장되도록 하고, save-saved.png를 사용할 것
- 저장된 글을 삭제하려면, waste-basket.png를 클릭할 것
  - 알림창(모달창)이 띄울 것
  - 텍스트로 '[현재 년/월/일 요일]일기를 삭제합니다. 계속 진행하시겠습니다? 를 배치할 것
  - 진행하려면 예(Y), 취소하려면 아니요(N) 버튼을 클릭하게 할 것
  - 예(Y) 버튼을 클릭하면, 삭제시키고, 한번 더 알림창이 띄워질 것
    - '삭제되었습니다.' 텍스트를 배치하고, 좌측에 letter-i.png를 사용할 것
    - 확인 버튼을 클릭하면 알림창이 사라지면서 초기화되고 시간을 붙잡다 모달창도 함께 사라질 것
  - 아니요(N) 버튼을 클릭하면, 삭제 취소시키고, 알림창 사라질 것
  - 알림창에 텍스트 좌측에 question-mark.png를 사용할 것

# 추가 수정 요청 사항(3)

- 저장시킨 글을 다시 직접 삭제를 하면, save-saved.png에서 save.png로 전환되도록 구현할 것
- 저장을 안시키고, 창 닫힘 버튼을 클릭하면, 알림창(모달창)이 띄울 것
  - 텍스트로 '변경 내용이 저장되지 않았습니다. 일기쓰기를 취소하시겠습니까?를 배치하고 좌측에
    question-mark를 사용할 것
  - 예(Y) 버튼을 클릭하면, 시간을 붙잡다 모달창이 사라질 것
  - 아니요(N) 버튼을 클릭하면, 알림창이 사라지고, 다시 글 쓰기 모드로 전환될 것

  # 추가 수정 요청 사항(4)
  - 삭제 버튼을 클릭할 때, 모달창의 아니오, 예 버튼 위치 순서를 바꿀 것
  - '2026년 8월 5일 수요일 일기를 삭제합니다.' 텍스트를 한줄에 표기하도록 모달창 가로 크기를 조정할 것
  - 저장시킨 글을 삭제를 해서, 본문 내용 박스를 비우면, 변경된 사항으로 간주하고, save-saved.png에서
    save.png로 전환되도록 구현할 것
  - 변경된 상태면 저장이 안된 상태로 간주하고, 창 닫기 버튼을 클릭하면, 알림창(모달창)이 띄울 것
  - 텍스트로 '변경 내용이 저장되지 않았습니다. 일기쓰기를 취소하시겠습니까?를 배치하고 좌측에
    question-mark를 사용할 것
  - 예(Y) 버튼을 클릭하면, 시간을 붙잡다 모달창이 사라질 것
  - 아니요(N) 버튼을 클릭하면, 알림창이 사라지고, 다시 글 쓰기 모드로 전환될 것

  # 추가 수정 요청 사항(5)
  - '변경 내용이 저장되지 않았습니다. 일기쓰기를 취소하시겠습니까?' 알림창의 아니오, 예 버튼 위치 순서를
    바꿀 것

  # 저장 기능 정리
  - 본문 내용을 반드시 입력해야 기본적으로 저장 기능을 사용할 수 있고, 날짜 선택, 기분 icon 선택, 날씨
    icon 선택, 이미지 첨부, 제목 입력이 부가적으로 함께 저장될 수 있도록 구현할 것

    '변경 내용이 저장되지 않았습니다. 일기쓰기를 취소하시겠습니까?' 알림창을 띄우지 말 것
