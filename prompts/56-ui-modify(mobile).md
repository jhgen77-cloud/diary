원인 (코드로 확인됨): 다른 모달들과 동일하게 size="xl"을 쓰지만, DataManager만 좌측 고정폭 사이드바(DataSidebar, w-24)+본문을 가로 flex로 배치하면서

- 본문 컬럼(DataManager.tsx 21행)에 min-w-0이 빠져 있고
- DataExportFormatOption.tsx의 설명 문구에 whitespace-nowrap이 걸려 있고
- DataResetPanel.tsx의 DB 경로 문구는 truncate가 있지만 부모에 min-w-0이 없어 무력화됨

이 조합 때문에 좁은 화면에서 줄바꿈되지 않고 내용이 원래 폭 그대로 강제되면서, 모달 박스 전체가 화면 밖으로 넘쳐버립니다(플렉스박스의 잘 알려진 min-width: auto 오버플로 문제). 다른 모달들은 이런 고정폭 사이드바+nowrap 구조가 없어서 문제가 없었던 것입니다.

(가로모드 캡처 7장 중 일부에서 텍스트가 겹쳐 보이는 건, 상단에 사파리 탭 바(여러 탭 아이콘 목록)가 함께 찍혀 있는 것으로 보아 사파리 탭 전환 시의 미리보기 썸네일 캐시일 가능성이 높습니다 — 실제 앱 렌더링 버그로 단정하기엔 근거가 약해 이번 결론에서는 제외했습니다.)

결론: PC UI를 그대로 두고 모바일만 수정 가능한가?

가능합니다. 이유:

1. 문제 범위가 DataManager와 그 하위 3개 컴포넌트로 국한되어 있어, 전역 레이아웃이나 Tailwind 브레이크포인트 체계를 건드릴 필요가 없습니다.
2. 해결책(설명 문구 줄바꿈 허용, 관련 flex 컨테이너에 min-w-0 추가)은 현재도 이미 있는 sm: 이상 브레이크포인트에 영향을 주지 않는 순수 좁은 화면용 보정이라, 640px 이상(PC 브라우저)에서는 시각적으로 아무 변화가 없습니다.
3. 나머지 화면들은 이미 모바일 대응이 되어 있어 추가 작업이 필요 없습니다.

확인해보니 실제로 근거가 있는 지적입니다.

원인: 현재 코드는 Tailwind 브레이크포인트를 (기본값) → sm(640px↑) → md(768px↑) 이렇게 단 두 단계로만 나눠 놨습니다. 즉 320px~639px에 해당하는 모든 폰(아이폰 SE, 12 미니, 최신 대화면 폰 등)이 전부 똑같은 "기본값" 크기를 씁니다.

예시:

- Header.tsx: 로고 "기억" 제목 text-5xl(48px) — sm 미만이면 폰 크기와 무관하게 항상 48px
- SettingsButton.tsx/InfoButton.tsx: 아이콘 버튼 h-9 w-9(36px) 고정
- DiaryMenuItem.tsx: 카드 제목 text-base(16px) 고정

이 값들은 px 고정값이라 화면 폭에 비례해서 줄어들지 않습니다. 아이폰 12 미니(375px, 물리 화면도 가장 작음)는 이 "기본값 구간" 중 제일 좁은 축에 속하는데도 큰 화면 폰과 똑같은 48px 제목·36px 아이콘을 그대로 쓰다 보니, 화면에서 차지하는 비중이 상대적으로 커 보이는 겁니다. IMG_0811에서 "기억" 제목이 화면 위쪽 상당 부분을 차지하는 것도 같은 이유입니다.

해결 가능한가?

가능합니다. 이것도 PC UI(sm:/md: 이상)는 전혀 건드리지 않고 고칠 수 있는 범위입니다. 방법은 두 가지:

┌───────────────────────────┬────────────────────────────────────────────────────────────┐
│ 방법 │ 설명 │
├───────────────────────────┼────────────────────────────────────────────────────────────┤
│ A. 폭이 더 좁은 │ 예: text-4xl sm:text-5xl 형태로 기본값을 한 단계 낮추고, │
│ 브레이크포인트 추가 │ 지금의 "기본값"을 sm:으로 한 칸씩 미룸 │
│ (권장) │ │
├───────────────────────────┼────────────────────────────────────────────────────────────┤
│ B. 유동 크기(clamp()) │ text-[clamp(2.25rem,9vw,3rem)]처럼 화면 폭에 비례해 │
│ 적용 │ 자동으로 줄어들게 함 │
└───────────────────────────┴────────────────────────────────────────────────────────────┘

두 방법 모두 640px 이상(PC)에는 영향이 없어, 지금 PC에서 보이는 모습은 그대로 유지됩니다.
