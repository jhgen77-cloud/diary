새 링크 페이지(데이터 관리 모달창)의 UI를 구현할 것

# 페이지 구성

    - Write(app\@modal\(.)data\page.tsx)의 목록 리스트와 연동할 것
    - 상단 헤더
      - 좌측: '기억의 유실을 회복하다'라는 제목을 상단에 배치할 것
    - 우측: 컴포넌트 화면 닫기 버튼을 배치할 것 (기존 구현 방식과 동일)
    - 메인 섹션
      - 좌측 사이드바에 ＂기억의조율”이라고 텍스트를 만들 것
      - 중앙 컴포넌트 상단에 ‘기억의귀환’,’기억의날개’,’기억의소멸’로
        컴포넌트를 구성할 것
         - 기억의귀환: 백업된 데이터 가져오기를 구성
         - 기억의날개:,백업할 데이터 내보내기를 구성
         - 기억의소멸: 저장된 데이터 초기화를 구성
         - 아래에 텍스트로 'ZIP 및 XML 파일로 백업한 일기로부터 데이터를
           가져와서 저장합니다.'라고 표기할 것
         - 텍스트 아래 박스를 설정하여 '가져오기 옵션 선택' 이라고 텍스트 배치
           다음 아래와 같이 텍스트 배치
            - 가져오기 옵션 선택하게 할 것(아래와 같이)
                . 가져오기 하지 않고 건너 뜀
                . 최종 수정 일시가 최근 날짜인 일기로 덮어 쓰기
                . 가져오기 대상 파일에 존재하는 일기의 내용으로 덮어쓰기
            - 가져오기 옵션 선택 아래 가져오기 버튼을 만들 것
        - 로컬 폴더에서 저장된 파일 가져오게 할 것


    - 데이터 관리 페이지의 디폴트로 구성은 ‘기억의소환’ 컴포넌트로 배치할 것
    - 화면 하단에 ‘닫기’ 버튼을 만들 것
    - 닫기 버튼을 클릭하면, 데이터 관리 페이지를 닫을 것

# 주의 사항

    - 컴포넌트 단위로 적절히 분할해서 구현할 것
    - 결과는 컴포넌트 단위로 보고할 것
    - 이미 만들어둔 컴포넌트를 최대한 활용할 것
