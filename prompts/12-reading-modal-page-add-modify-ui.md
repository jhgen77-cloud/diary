새 링크 페이지(일기 보기 모달창)의 UI를 구현할 것

# 수정 및 추가 요청(1)

- 현재 년/월/일 요일이 좌측 끝에 배치되어 있는데, 우측 waste-basket.png와 writing1.png icon 바로 밑으로 배치할 것
- 현재 'NaN년 NaN월 NaN일 NaN:NaN에 작성된 일기입니다.' 로 날짜 표기 버그가 발생했으니, 글 작성된 날짜 기준으로 '[작성된 년/작성된 월/작성된 일 작성된 시간]에 작성된 일기입니다.' 라고 텍스트를 표기할 것

# 수정 및 추가 요청(2)

- 등록된 기분/날씨 icon, 제목 텍스트, waste-basket.png와 writing1.png icon, 현재 년/월/일 요일 텍스트가 있는 구역을 박스로 구분하고, 상하 간격을 약간 좁혀서 내용물을 상하 위치를 조정할 것
- 새 링크 페이지(일기 보기 모달창)의 세로 크기를 3분의 2 정도로 조정할 것

# 수정 및 추가 요청(3)

- 제목이 있는 박스 세로 크기를 좁혀서 기분/날씨 icon과 제목 텍스트 상하
  간격을 조정할 것
- 우측 끝에 배치된 휴지통, 글쓰기 아이콘과 현재 년/월/일 요일 텍스트 간격을
  좌측 끝에 있는 기분/날씨 icon과 제목 텍스트과의 상하 간격을 맞출 것

# 수정 및 추가 요청(4)

- 제목이 있는 박스의 세로 크기를 더 줄일 것
- 우측 휴지통/글쓰기 아이콘과 년/월/일 요일 텍스트 간격이 좌측 분/날씨 icon과 제목 텍스트과의 상하 간격과 불일치하니, 균일하게 맞출 것

# 수정 및 추가 요청(5)

- 기분/날씨 아이콘과 휴지통/글쓰기 아이콘과의 사이즈가 안맞으니,
  동일하게 맞춰주고, 제목 텍스트와 현재 년/월/일 요일 텍스트 가로 배치가
  맞게 조정할 것

# 수정 및 추가 요청(6)

- 휴지통/글쓰기 아이콘 사이즈가 기분/날씨 아이콘 사이즈 보다 조금 작아
  보이니, 동일한 사이즈로 구현할 것

# 수정 요청

- 일기를 찾을 수 없습니다. 삭제되었거나 잘못된 링크일 수 있습니다. 라는
  메시지가 뜨는데, 기존 구현된 '삭제되었습니다.' 라는 알림창으로 대체하고, 좌측에 letter-i.png를 사용할 것
  - 확인 버튼을 클릭하면, 모달창이 사라지게 할 것
