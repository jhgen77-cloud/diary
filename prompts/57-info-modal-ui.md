새 링크 페이지(정보 모달창)의 UI를 구현할 것

# 페이지 구성

    - Write(app\@modal\(.)data\page.tsx)의 목록 리스트를 참고하여
      모달창 레이아웃을 구현할 것
    - 상단 헤더
        - 좌측: 정보라는 제목을 상단에 배치할 것
        - 우측: 컴포넌트 화면 닫기 버튼을 배치할 것 (기존 구현 방식과 동일)
    - 메인 섹션
        - 좌측 사이드바 첫번째 줄에에 '버전 정보”이라고 텍스트를 만들 것
                       두번째 줄에는 도움말 버튼을 만들것
                        - 도움말 버튼 클릭하면 도움말 페이지를 구현할 것
                            - 아직 내용은 적지 말것
    - 화면 하단에 ‘닫기’ 버튼을 만들 것
    - 닫기 버튼을 클릭하면, 데이터 관리 페이지를 닫을 것

# 주의 사항

    - 컴포넌트 단위로 적절히 분할해서 구현할 것
    - 결과는 컴포넌트 단위로 보고할 것
    - 이미 만들어둔 컴포넌트를 최대한 활용할 것
