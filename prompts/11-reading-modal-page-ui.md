새 링크 페이지(일기 보기 모달창)의 UI를 구현할 것

# 페이지 구성

- Write(app\@modal\(.)diary\write\page.tsx)에서 작성해서 저장한 글을
  볼 수 있게 구현할 것
  - Write(app\@modal\(.)diary\page.tsx)와 Write(app\diary\calendar\page.tsx)의 목록 리스트와 연동할 것

- 상단 헤더
  - 좌측: '그날을 거닐다'라는 제목과 저장된 년/월/일을 텍스트로 상단에
    배치할 것
  - 우측: 컴포넌트 화면 최소화,최대화,닫기 버튼을 배치할 것 (기존 구현 방식과 동일)
  - 제목 아래에 저장된 기분 및 날씨 아이콘을 배치할 것
  - 우측에 waste-basket.png와 writing1.png icon을 배치할 것
  - waste-basket.png 버튼을 누르면, 알림창이 띄울 것
  - 알림창에 텍스트로 '[현재 년/월/일 요일]일기를 삭제합니다. 계속 진행하시겠습니다? 를 배치할 것
- 진행하려면 예(Y), 취소하려면 아니요(N) 버튼을 클릭하게 할 것
- 예(Y) 버튼을 클릭하면, 삭제시키고, 한번 더 알림창이 띄워질 것
  - '삭제되었습니다.' 텍스트를 배치하고, 좌측에 letter-i.png를 사용할 것
  - 확인 버튼을 클릭하면 알림창이 사라지면서 초기화되고 시간을 붙잡다 모달창도 함께 사라질 것
- 아니요(N) 버튼을 클릭하면, 삭제 취소시키고, 알림창 사라질 것
- 알림창에 텍스트 좌측에 question-mark.png를 사용할 것
- writing1.png를 클릭하면, Write(app\@modal\(.)diary\write\page.tsx)로
  연동되어 작성된 해당 글을 불러올 것
- 작성된 본문 내용 박스 하단 좌측에 글이 작성된 날짜를 '[년/월/작성시간]에 작성된 일기입니다.' 라고 텍스트를 표기할 것
