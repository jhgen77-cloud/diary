# 페이지 구성

    - 메인 페이지의 settings.png를 클릭하면, 환경 설정 모달창을 구현할 것
        - 레이아웃을 기억의 유실을 회복하다 모달창을 활용할 것
        - 메인 섹션
            - 좌측 사이드바에 '기억의 편집' 라고 텍스트 설정
            - 중앙 컴포넌트 상단에 ‘폰트설정’,’배경설정’ 컴포넌트
              구성할 것
            - 폰트설정 기능을 아래와 같이 구현할 것
                - 폰트명: Font Family (폰트 패밀리) 기능 구현할 것
                - 폰트크기: <!-- 현개 폰트 사이즈 명시만 하고, 크기 선택
                           기능은 없음 -->
                - 폰트색상: <!-- 검정색 RGB 색상만 명시하고, 폰트 색상 선택 기능은 없음 -->
                - 정렬기준: Text Alignment (텍스트 정렬) 기능 구현할 것

            - 배경설정 기능을 아래와 같이 구현할 것
                - 배경타입
                    - 배경타입 옵션: 없음 / 단색 선택 가능 설정
                    - 배경색상 옵션
                        - 배경타입 옵션에서 '없음' 선택이면, 색상선택 버튼
                          비활성화
                        - 배경타입 옵션에서 '단색' 선택이면, 색상선택 버튼
                          활성화되고, <!-- Color Palette(컬러 팔레트) 기능 구현할 것 -->

# 수정 사항

    - 배경타입 옵션에서 '단색' 선택 시, 색상 선택 기능은 Combined Color Palette (통합형 컬러 팔레트)으로 구현할 것
    - 폰트크기: Font Size (폰트 사이즈 / 글자 크기)를 구현할 것
               폰트크기는 16px이 기본 설정되게 할 것
    - 폰트색상: 배경색상 옵션 기능과 동일하게 Combined Color Palette
                (통합형 컬러 팔레트)으로 구현할 것
    - 배경타입 옵션에서 '단색'이 기본으로 되어 있을 것
    - '폰트명','폰트크기','폰트색상','정렬기준','배경타입','배경색상'의
       텍스트의 박스 사이즈를 동일하게 조정할 것
        - '폰트크기' 텍스트의 박스 사이즈에 맞출 것
    - 배경설정의 배경타입에서 없음 버튼이 기본 활성화 되게 설정할 것

# 기능 구현

    - Write(app\@modal\(.)diary\write\page.tsx)의 시간을 붙잡다
      모달창에서만 환경 설정 기능이 구현되도록 할 것
      - 제목란
            - 폰트명 기능 구현 가능
            - 폰트 색상 기능 구현 가능
            - 폰트 크기 기능 구현 안함
            - 배경설정 기능 구현 안함
        - 본문 내용 설정란
            - 폰트명, 폰트크기, 폰트색상,정렬기준, 배경설정 기능 구현 가능
    - 저장 시, 해당 기능도 함께 반영되도록 구현할 것
    - 레이아웃 하단 우측에 확인 , 취소, 적용 버튼을 구현할 것
        - 확인: 적용 완료 후 확인 버튼을 클릭 시, 환경 설정 모달창이
               사라지게 할 것
        - 취소: 폰트설정 및 배경설정을 해도, 취소 버튼을 누르면 반영이
                안되고 모달창이 사라지게 할 것
        - 적용: 폰트설정 및 배경설정을 한 후, 적용 버튼을 클릭하면,
                실제 반영되도록 할 것
                적용 버튼 클릭 후, 적용 완료되면, '적용 완료했습니다.'
                라는 알림창을 구현할 것
                알림창 뜨고, 잠시 후 자동 사라지게 할 것

# 주의 사항

    - 컴포넌트 단위로 적절히 분할해서 구현할 것
    - 결과는 컴포넌트 단위로 보고할 것
    - 이미 만들어둔 컴포넌트를 최대한 활용할 것
