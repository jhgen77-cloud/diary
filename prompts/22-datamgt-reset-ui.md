새 링크 페이지(데이터 관리 모달창-기억의 소멸)의 UI를 구현할 것

# 페이지 구성

- 메인 섹션
  - 중앙 컴포넌트 상단의 ‘기억의 귀환’,’기억의 날개’,’기억의 소멸’
    컴포넌트 아래 좌측에 '기억의 은하'로 텍스트와 박스를 구현하여 배치할 것
    - 텍스트 바로 옆에 데이터가 저장되어 있는 데이터베이스 경로를 표기할 것
      데이터베이스는 아직 구현 안함
  - '기억의 은하'' 텍스트 바로 아래에 기억의 소멸' 텍스트와 박스를 구현하여
    배치할 것
    - 기억의귀환 컴포넌트 바로 아래 배치
  - '기억의 소멸' 텍스트 우측에 '모든 데이터를 삭제합니다.' 텍스트를 배치할 것
    텍스트 좌측에 체크 박스도 구현할 것
  - 데이터 초기화 버튼을 우측 가장자리에 배치할 것
    - 기본 비활성 상태로 구현할 것
    - 버튼명을 '소멸'이란 텍스트로 설정할 것
  - '기억의 소멸' 텍스트 우측에 '모든 데이터를 삭제합니다.' 체크 박스를 클릭하면
    - 비활성 상태의 초기화 버튼이 활성화시킬 것
  - '소멸' 버튼 클릭 시, 글 작성자가 데이터베이스에 저장해 놓은 모든 데이터가
    초기화되도록 구현
    데이터베이스는 아직 구현 안됨

# 주의 사항

    - 컴포넌트 단위로 적절히 분할해서 구현할 것
    - 결과는 컴포넌트 단위로 보고할 것
    - 이미 만들어둔 컴포넌트를 최대한 활용할 것
