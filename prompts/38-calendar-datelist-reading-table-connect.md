# 달력 검색 리스트, 날짜별 목록 리스트, 글 읽기 리스트 테이블 연결 구성

    - 달력 검색 리스트 테이블과 날짜별 목록 리스트 테이블 그리고  글 읽기
      리스트 테이블을 연결할 것
        - 달력 검색 리스트 테이블과 날짜별 목록 리스트 테이블에
          memory_entries_id라는 컬럼을 추가할 것
        - memory_entries_id 컬럼은 선택적 컬럼으로 설정할 것
        - memory_entries_id 컬럼이 글 읽기 리스트 테이블의 id 컬럼을
          참조하도록 외래키로 설정할 것
        - 글 읽기 리스트 테이블의 데이터가 삭제될 경우, 연결된
          달력 검색 리스트 테이블과 날짜별 목록 리스트 테이블의
          memory_entries_id를 빈 값으로 설정할 것
