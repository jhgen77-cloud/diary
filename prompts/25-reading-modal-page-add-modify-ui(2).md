글 쓰기/일기 보기 페이지의 기능 수정 및 추가 구현할 것

# 수정 구성(1)

    - Write(app\@modal\(.)diary\write\page.tsx)에서 글쓰기 후 저장을 하면
      그날을 거닐다의 일기 보기에서 본문 내용에 첨부된 이미지만 보이고, 텍스트는 안보이고 있음
      삭제된 것이면, 함께 저장하고, 밑에 가려서 안보이는 것이면 한 화면에 모두
      보이도록 수정할 것
         - 저장될 때 본문 내용 텍스트도 첨부된 이미지와 함께 저장되어야 함

# 수정 구성(2)

- Write(app\@modal\(.)diary\page.tsx)에서 작성된 본문 내용의 '[년/월/작성시간]에 작성된 일기입니다.' 텍스트를 위치를 항상 레이아웃 좌측 하단에 배치할 것

# 주의 사항

    - 컴포넌트 단위로 적절히 분할해서 구현할 것
    - 결과는 컴포넌트 단위로 보고할 것
    - 이미 만들어둔 컴포넌트를 최대한 활용할 것
