# 추가 수정 사항

    - 기억의 날개에서 내보내기 할때 기존 글을 수정했음
      이미지가 있는 글을 본문 내용 텍스트만 수정했는데, 첨부되어 있어야할 이미지가 writing.png 버튼을 클릭하면 삭제가 됨.
      변경하는 내용만 수정하고 나머지는 모두 기존대로 유지될 수 있도록 검증 후
      수정할 것

    - 내보내기 하면서 데이터를 삭제하고 내보내기했음
      다시 내보낸 데이터를 가져오기했음
      날짜 목록 리스트에는 가져온 데이터가 확인됨
      다만, supabase의 memory_entries 테이블에는 초기화되어 있음
      가져오기로 가져온 데이터로 다시 supabase의 memory_entries 테이블에
      등록되어야하지 않나요?
      검증 후 수정할 것

    - 날짜별 목록 리스트에서 등록된 기존 글을 클릭하고, 수정을 위해 시간을 붙잡다
      글 쓰기 모달창에 들어가면 저장 버튼이 비활성화 되어 있음
      첨부된 파일도 초기화되어 있음
      검증 후 수정할 것

    - supabase id 칼럼: 23, text 칼럼: empty로 되어 있음
      날짜별 목록 리스트에도 본문 내용이 없으면 저장이 안되어야 하는데,
      저장된 채로 남아 있음
      초기 글 작성에는 본문 내용 작성한 것으로 알고 있는데, 현재 비어 있음
      데이터가 유실된 것으로 추정되니, 검증 후 수정할 것
