새 링크 페이지(데이터 관리 모달창-기억의 날개)의 UI를 구현할 것

# 페이지 구성

    - components/DataExportPanel.tsx와 연동할 것
    - 메인 섹션
         - 텍스트의 'ZIP 및 XML 파일로 백업한 일기로부터 데이터를
           가져와서 저장합니다.' 위치에 아래와 같이 텍스트만 변경할 것
          - '작성한 글을 외부 파일로 내보내기 합니다.'

         - 텍스트 아래 박스를 설정하여 '파일 형식 선택' 이라고 텍스트 배치
           다음 아래와 같이 텍스트 배치
             . ZIP 파일
              - 이미지를 포함한 전체 내용을 내보내기 합니다. 나중에 [가져오기]를 통해서 다시 복원할 수 있습니다.
             . TXT 파일
              - 이미지를 제외한 텍스트 데이터만 백업합니다. 암호화된 일기는 내보내기 대상에서 제외됩니다.
            - '파일 생성 옵션' 이라고 텍스트 배치
            - 텍스트 옆에 TXT파일 선택을 하면 선택란이 활성화 되게 할 것
              - top-down 방식으로 아래 텍스트를 나열할 것
                - 연도별로 파일 생성
                - 하나의 파일로 내보내기
                - 연,월별로 파일 생성
                - 날짜별로 파일 생성
        - 로컬 폴더로 저장된 파일 내보내기 구현할 것

        - 파일 형식 선택 박스 하단에 박스를 설정하여 '일기 날짜 선택'이라고
          텍스트 배치
          - 좌측에 '시작 일자' 텍스트를 박스로 쳐서 배치하고 옆에 연/월/일
            선택할  수 있는 선택란 구현할 것
          - 바로 아래 좌측에 '종료 일자' 텍스트를 박스로 쳐서 배치하고 옆에
            연/월/일 선택할 수 있는 선택란 구현할 것
          - '시작 일자'의 년/월/일 옆에 '전체 글 내보내기' 텍스트를 배치하고
             텍스트 바로 좌측 옆에 체크 박스를 선택해서 전체 글 내보내기 기능을
             구현할 것
          - '종료 일자' 텍스트 박스 밑에 체크박스 배치하고, '내보내기 완료 후
             내보내기한 글을 삭제합니다.' 텍스트를 배치할 것
          - 우측 가장자리에 내보내기 버튼을 배치할 것
            - 내보내기 버튼을 클릭하면 로컬 폴더가 팝업되어 내보내기 기능을
              구현할 것

# 주의 사항

    - 컴포넌트 단위로 적절히 분할해서 구현할 것
    - 결과는 컴포넌트 단위로 보고할 것
    - 이미 만들어둔 컴포넌트를 최대한 활용할 것
