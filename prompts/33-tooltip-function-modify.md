툴팁(Tooltip) 기능 수정

# 수정 사항(2)

    - 버튼 타입의 툴팁 기능은 아래와 같이 수정할 것
       - 버튼 타입의 툴팁이 활성화될 때, 버튼을 누른 상태면, 툴팁이
         사라지지 않고 잔상이 남는 것처럼 유지됨
         바로 마우스 커서가 다른 버튼으로 이동하면, 툴팁이 이중으로 보임
        - 버튼 클릭을 기준으로 하지 말고, 마우스 커서 위치를 기준으로
          툴팁 기능이 활성화되도록 수정할 것

# 주의 사항

    - 컴포넌트 단위로 적절히 분할해서 구현할 것
    - 결과는 컴포넌트 단위로 보고할 것
    - 이미 만들어둔 컴포넌트를 최대한 활용할 것
