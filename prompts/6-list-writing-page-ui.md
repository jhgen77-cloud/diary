새 링크 페이지의 UI를 구현할 것

# 페이지 구성

    - Write(app\@modal\(.)diary\write\page.tsx)와 연동하여 구현할 것
    - 백그라운드에 사각형 테두리를 이쁘게 구현하고, 제목과 컴포넌트 간 분리를 할 것
    - 컴포넌트끼리 구분될 수 있도록 희미하게 박스를 구현할 것

    - 상단 헤더
    - 좌측: ‘시간을 붙잡다’로 텍스트 로고 배치할 것
    - 우측: 컴포넌트 화면 최소화,최대화,닫기 버튼을 배치할 것
    - 메인 섹션
    - 상단에 좌측에서 우측으로 순차적으로 save.png, calendar.png, waste-basket.png, image-attachment.png icon을 사용하여 배치할 것
    - icon은 C:\webdev\diary\images를 사용할 것
    - icon은 바탕화면 비율에 맞게 조정하고, 텍스트 사이즈는 icon과 맞출 것
    - icon 아래에 좌측에 top-down방식으로, 날짜,기분,제목 텍스트를 설정하고
      박스로 구분할 것
    - 날짜 텍스트 옆에 선택란을 구현하고, 현재 년/월/일/요일을 설정해서, 좌측에 달력
      아이콘을 배치하여, 달력 아이콘을 클릭하면 조그만 달력창이 뜨게 하며, 달력창에서
      날짜를 선택할 수 있게 구현할 것
    - 기분 텍스트 옆에 좌측에서 우측 순으로 기분 아이콘을 6개를 선택할 수 있게
      배치할 것
      또한 기분 아이콘 옆에, 날씨라고 텍스트를 설정해서 박스로 구분하고, 날씨를 선택할 수 있는 선택란을 구현하여, 날씨 아이콘을 top-down 방식으로 6개 나열하여 선택할 수 있게 구현할 것

    - 기분 아이콘은 아래 경로에 있는 아이콘을 이용할 것
      C:\webdev\Diary\images\mood
    - 날씨 아이콘은 아래 경로에 있는 아이콘을 이용할 것
      C:\webdev\Diary\images\weather
    - icon은 비율에 맞게 작게 조정하고, 텍스트 사이즈는 icon과 맞출 것
    - 기분 및 날씨 아이콘에 마우스를 놓으면 텍스트로 아래와 같이 보여지게 할 것
        - angry.png: 화남
        - bad.png: 기분나쁨
        - sad.png: 슬픔
        - sarcastic.png: 냉소
        - smile.png: 행복
        - no-select.png: 선택안함
        - brightness.png: 맑음
        - cloudy.png: 흐림
        - haze.png: 안개
        - rain.png: 비

# 주의 사항

    - 컴포넌트 단위로 적절히 분할해서 구현할 것
    - 결과는 컴포넌트 단위로 보고할 것
    - 이미 만들어둔 컴포넌트를 최대한 활용할 것

# 수정 요청 사항

    - 제목 컴포넌트는 기분 아래에 배치할 것
    - 날씨 텍스트와 C:\webdev\Diary\images\weather의 icon은 기분 텍스트와 C:\webdev\Diary\images\mood의 icon이 배치한 줄에 같이 배치할 것
    C:\webdev\Diary\images\weather의 icon은 선택바를 구현하여 클릭하면 아래로
    나열되도록 구현할 것
    - 본문 내용은 별도 박스를 쳐서 분리하고, 내용 작성 가능하도록 구현할 것
    기분 텍스트와 icon 날씨 텍스트와 icon이 현 상태로는 한줄에 다 배치하기에는 사이즈가 좀 크니 조정할 것

# 추가 수정 요청 사항

    - 제목: 본문은 삭제하고 작성란 박스를 하나로 해서 분리할 것
    - 날짜, 기분, 제목, 컴포넌트 높이를 줄여서 작성란 박스를 더 키울 것
    - icon 사이즈도 약간 줄여도 무방함

# 추가 수정 요청 사항(2)

    - 날짜, 기분, 제목 텍스트는 좌측 사이드에 박스로 구분하고, 박스를 가로,세로
      간격을 맞춰줄 것
    - 날짜, 기분, 제목 컴포넌트는 높이 간격을 약간 줄일 것
    - 작성란은 별도 박스로 만들어서 날짜,기분,제목 컴포넌트와 구분하고, 작성란 세로를
      많이 키울 것
    - 날짜 컴포넌트에서 달력 선택바는 우측 가장자리에 배치해서 년/월/일 텍스트와
      분리 할 것
    - 날씨 텍스트는 박스로 구분하고 날씨 아이콘은 우측 가장자리에 배치할 것
    - 날씨 아이콘은 클릭하면 아래로 나열하되 세로로 한줄로 곧게 나열되도록 구현할 것

# 추가 수정 요청 사항(3)

    - 모달창을 세로로 더 키워주고, 작성란은 그만큼 세로로 넓혀줄 것
    - 날씨 아이콘 위치를 우측 가장자리 끝에 위치해서 달력 아이콘 바로 밑에 위치하도록
      조정할 것
    - 그 외에는 구현하지 말 것

# 추가 수정 요청 사항(4)

    - 날씨 아이콘 중, brightness.png 아이콘이 클릭 시, 나열될 때 이중으로 구현되지 않게 수정할 것
    - 날씨 아이콘 모두 사이즈가 동일하게 조정할 것
    - 모달창을 세로로 크게 구현해달라고 했는데, 구현이 안됐으니 다시 조정할 것

# 추가 수정 요청 사항(5)

    - 날씨 텍스트는 기분 아이콘의 선택안함 아이콘 바로 우측 옆에 배치하고 박스
      분리는 아이콘 박스와 분리할 것
    - 날씨 선택란에서 [선택안함] 텍스트를 추가하여 기본 배치되게 하고,
      클릭하면 날씨 아이콘이 바로 밑에 한줄로 아래로 나열되게 구현할 것
    - 날씨 선택 시 선택안함 텍스트도 날씨 아이콘과 동일하게 선택 가능하게 구현할 것
    - 선택안함 텍스트와 날씨 아이콘은 달력 아이콘 바로 밑에 배치되도록 우측 가장자리에
      다시 배치할 것
    - 날씨 텍스트는 기분 아이콘 중 선택안함 아이콘 바로 우측 옆에 배치하게 하고
      날씨 텍스트 박스 구성한것과 또 박스 구성한 것을 분리하여 가로로 꽉차게
      넓게 배치할 것
