새 링크 페이지(데이터 관리 모달창-기억의 날개)의 UI를 구현할 것

# 수정 사항(1)

    - '- 이미지를 포함한 전체 내용을 내보내기 합니다. 나중에 [가져오기]를 통해서
       다시 복원할 수 있습니다.'를 한줄 텍스트 배치 가능하게 가로 사이즈를 조정할 것
    - '- 이미지를 제외한 텍스트 데이터만 백업합니다. 암호화된 일기는 내보내기
       대상에서 제외됩니다.'를 한줄 텍스트 배치 가능하게 가로 사이즈를 조정할 것
    - '- 파일 생성 옵션'은 파일 형식 선택 옵션 중 하나인 TXT 파일의 하위 구성으로
      구현할 것
        - '파일 생성 옵션' 텍스트 위치를 상단 '이미지를 제외한...' 텍스트와 좌측 동일 위치로 배치할 것

# 주의 사항

    - 컴포넌트 단위로 적절히 분할해서 구현할 것
    - 결과는 컴포넌트 단위로 보고할 것
    - 이미 만들어둔 컴포넌트를 최대한 활용할 것
