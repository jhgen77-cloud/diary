새 링크 페이지(데이터 관리 모달창-기억의 날개)의 파일 형식 선택 UI를 수정

# 수정 사항(2)

        - 텍스트 옆에 TXT파일 선택을 하면 선택란이 활성화 되게 할 것
         - 파일 생성 옵션을 선택할 수 있는 선택란을 구현하여, top-down 방식으로
           4개의 텍스트를 나열하여 선택할 수 있게 구현할 것
           - 텍스트 나열되기 전 최초 배치될 텍스트는 '연도별로 파일 생성'로
             배치할 것
             - 다른 옵션으로 선택이 되면, 해당 옵션 텍스트로 전환시킬 것
           - 선택란을 클릭하면, 아래와 같이 순차적으로 top-down 방식으로
             텍스트를 나열할 것
                - 하나의 파일로 내보내기
                - 연도별로 파일 생성
                - 연,월별로 파일 생성
                - 날짜별로 파일 생성
            - 닫기 버튼 클릭 후, 선택란 텍스트 배치는 초기화되어 최초로 배치된
              '연도별로 파일 생성'로 원복

# 수정 사항(3)

- 파일 생성 옵션 선택란 위치를 '파일 생성 옵션' 텍스트 바로 옆 우측에 배치할 것

# 수정 사항(4)

- 선택란에서 옵션인 텍스트를 클릭하면, 첫 위치에 배치되게 하고, 닫기 버튼을 누르기
  전까지는 유지할 것
- 닫기 버튼을 누를 때, 선택란 텍스트 배치는 최초로 배치된 '연도별로 파일 생성'로
  원복할 것

# 수정 사항(5)

- 중앙 상단의 컴포넌트인 ‘기억의귀환’,’기억의날개’,’기억의소멸’ 컴포넌트를
  클릭하면, 선택란에서 선택된 텍스트가 초기화되고 있으니, 이것도 유지될 수
  있게 구현할 것

# 주의 사항

    - 컴포넌트 단위로 적절히 분할해서 구현할 것
    - 결과는 컴포넌트 단위로 보고할 것
    - 이미 만들어둔 컴포넌트를 최대한 활용할 것
