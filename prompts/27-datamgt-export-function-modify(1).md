데이터 관리 모달창-[기억의 날개]의 파일 형식 선택 UI를 추가 및 수정

# 추가 사항(1)

- 기역의 날개 컴포넌트에서 파일 형식 선택 옵션이 ZIP 파일과 TXT파일로
  정의되어 있을 것임
  - ZIP파일의 기능을 아래와 같이 추가할 것
    - 기능을 TXT 파일 옵션처럼 구현할 것
    - 파일 생성 옵션도 TXT 파일 옵션과 동일하게 구현할 것

# 주의 사항

    - 컴포넌트 단위로 적절히 분할해서 구현할 것
    - 결과는 컴포넌트 단위로 보고할 것
    - 이미 만들어둔 컴포넌트를 최대한 활용할 것
