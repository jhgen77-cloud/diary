새 링크 페이지(데이터 관리 모달창-기억의 소멸)의 UI를 구현할 것

# 수정 사항(1)

- 메인 섹션
  - '기억의 은하' 와 '기억의 소멸' 텍스트 박스는 '기억의 은하' 와 '기억의 소멸'
    텍스트에 한정해서 설정하도록 수정할 것
  - '저장된 모든 일기 데이터를 초기화합니다. 이 작업은 되돌릴 수 없습니다.'
    텍스트는 삭제할 것

# 추가 사항(1)

- '소멸' 버튼을 클릭하면, 데이터 초기화 시 알림 창을 띄울 것
  - 알림창에는 '데이터베이스 초기화가 완료되었습니다.' 텍스트를 중앙에
    배치하고, 'letter-i.png를 텍스트 좌측에 배치할 것

# 추가 사항(2)

- '데이터베이스 초기화가 완료되었습니다.' 텍스트를 한줄로 표시되게 알림창 가로
  사이즈를 조정할 것

# 추가 사항(3)

- 데이터 초기화 후, 저장된 데이터가 없어도, '모든 데이터를 삭제합니다.'
  체크 박스를 클릭하면, '소멸' 버튼을 활성화 시킬 것
  - '소멸' 버튼을 클릭하면, 데이터가 없는 경우 아래와 같이 알림창을 구현할 것
-     - '초기화 할 데이터가 없습니다.'
      - 텍스트는 한줄로 표시할 것

# 수정 사항(2)

- 데이터 초기화 완료 후, '현재 저장된 일기 0개가 모두 삭제됩니다.' 보이는데
  이런 문구는 필요없으니 삭제할 것

# 주의 사항

    - 컴포넌트 단위로 적절히 분할해서 구현할 것
    - 결과는 컴포넌트 단위로 보고할 것
    - 이미 만들어둔 컴포넌트를 최대한 활용할 것
