# 회원가입 기능을 구현할 것

- 이메일, 비밀번호, 비밀번호 확인 인풋 모두 입력해야만 회원가입 버튼을
  클릭할 수 있도록 설정할 것
- 회원가입 버튼을 클릭하면 비밀번호 일치 여부를 확인할 것
- 회원가입 실패하면 한국말로 오류 메세지를 화면 상단에 토스트 메세지로 나타낼 것
- 회원가입 성공하면 메인 인덱스 페이지로 이동할 것

# 비밀번호 설정 규칙 구현할 것

- 최소 8자 이상
- 문자 조합: 영문 소문자, 숫자, 특수문자 조합을 사용하도록 설정
- 허용 특수문자: ! @ # $ % ^ & \* ( ) \_ - + = 등 32자 내외의 표준 ASCII 문자
