# 수정 구성(1)

- 메인 섹션
  - 최종 수정 일시가 최근 날짜인 일기로 덮어 쓰기 -> 텍스트 및 기능 삭제할 것
  - 가져오기 대상 파일에 존재하는 일기의 내용으로 덮어쓰기
    - 같은 날짜의 일기가 존재하면, 가져오기 대상 파일의 내용으로 덮어 쓰기
      기능을 구현할 것
      가져오기 대상의 파일이 수정되어도 덮어 쓰기 가능
  - 가져오기 옵션에서 ZIP파일을 선택하고 가져오기 버튼을 클릭하면, '파일을 가져
    오는 중 요류가 발생했습니다.' 라는 경고창이 발생하는데, 왜 오류가 나는 것인지
    검증하고 ZIP파일을 불러올 수 있게 수정할 것
  - ZIP 파일을 압축 풀기하고 개별 파일(xml)파일을 클릭하면, '가져올 일기를 찾지 못했습니다.' 라고 경고창이 발생하는데, 왜 오류가 나는 것인지 검증하고 xml파일을
    불러 올 수 있게 수정할 것
    이미지 파일도 동일하게 검증하고 수정할 것
